# SADDAM BARBER — موقع صالون صدام للحلاقة

موقع تعريفي كامل (عربي / RTL) لصالون حلاقة: خدمات، عروض بخصومات، معرض صور،
قسم «فروعنا» بخريطة لكل فرع، آراء العملاء، ونموذج حجز مواعيد.

## تشغيل الموقع محلياً

### الطريقة السريعة (بتجهّز كل حاجة لوحدها)

```bash
npm run dev:up
```

السكربت ده بيشتغل: تثبيت الحاجات → تجهيز PostgreSQL محلي → بناء الجداول وزرع البيانات →
تشغيل الموقع على <http://localhost:3000>

### الطريقة اليدوية

```bash
cp .env.example .env        # وعدّل DATABASE_URL حسب إعداداتك
npm install
npx drizzle-kit push --force   # بناء الجداول
npm run seed                   # زرع البيانات
npm run dev                    # http://localhost:3000
```

> لو قاعدة البيانات مش متاحة، الموقع **مش بيفصل** — بيشتغل تلقائياً بالبيانات
> الثابتة الموجودة في `src/data/seed-data.ts`.

## نشر نسخة GitHub Pages (النسخة الثابتة)

النشر بيحصل تلقائياً: أي دفع على فرع `main` بيشغّل
[workflow النشر](.github/workflows/deploy-pages.yml) اللي بيبني نسخة ثابتة ويرفعها على Pages.

للتجربة محلياً **بنفس مسار GitHub Pages** (مهم جداً):

```bash
npm run build:pages      # بينتج مجلد out/
npm run preview:static   # يعرضها على http://localhost:4000/SaddamBarberr/
```

### ⚠️ قاعدة مهمة

GitHub Pages بيخدم الموقع على `/<اسم-المستودع>` وليس على الجذر، والمستودع اسمه
`SaddamBarber`، فالمسار هو **`/SaddamBarber`**.

لازم `NEXT_PUBLIC_BASE_PATH` يساوي نفس المسار في بناء نسخة Pages
(الـ workflow بيظبطه تلقائياً). لو المسار غلط، ملفات CSS/JS والصور كلها بترجع 404
والصفحة تظهر بدون تصميم وبدون أي تفاعل.

نفس المتغير مستخدم في `next.config.ts` وفي `src/lib/base-path.ts` (دالة `asset()`)
علشان مسار الصفحة ومسار ملفات الصور يبقوا متطابقين دايماً.

### نسخة Pages بتشتغل إزاي؟

- مفيش قاعدة بيانات ومفيش API routes → الصفحة بتتبني بالبيانات الثابتة.
- نموذج الحجز بيحوّل الطلب لواتساب تلقائياً (زر «ابعت الحجز على واتساب»).

## لوحة التحكم — عدّل كل حاجة من غير كود 🎛️

بعد تشغيل الموقع افتح:

```
http://localhost:3000/admin
```

كلمة السر الافتراضية: **`saddam2026`** — غيّرها من ملف `.env`:

```bash
ADMIN_PASSWORD=كلمة-السر-الجديدة
```

### إيه اللي تقدر تعدّله من اللوحة؟

| التبويب | بتتحكم في إيه |
| --- | --- |
| **الخدمات** | الاسم، الوصف، السعر، المدة، الصورة، القسم، الفروع المتاحة فيها، الترتيب، الإظهار/الإخفاء |
| **العروض** | العنوان، التفاصيل (كل سطر = نقطة)، السعر قبل/بعد، الشارة، الصورة، تاريخ الانتهاء |
| **الفروع** | الاسم، العنوان، التليفون، الواتساب، المواعيد، الإحداثيات (مكان الدبوس على الخريطة)، تقييم جوجل، صورة قائمة الأسعار |
| **معرض الصور** | إضافة/حذف/ترتيب صور السلايدر |
| **الفريق** | الحلاقين وبياناتهم وصورهم |
| **آراء العملاء** | آراء مكتوبة بتظهر فوق تقييمات جوجل |
| **الحجوزات** | كل الحجوزات الجاية من الموقع + تغيير حالتها (في الانتظار / مؤكد / تم / ملغي) |
| **قاعدة البيانات** | تبويب عرض فقط: كل الجداول وعدد الصفوف ومحتواها (بديل مدمج عن أي برنامج خارجي) |
| **إعدادات الموقع** | اسم الصالون، اللوجو، رقم التليفون والواتساب، **البريد الإلكتروني**، العنوان والمواعيد، لينكات السوشيال، صورة ونصوص الواجهة الرئيسية، وعناوين كل الأقسام |

### حاجات مهمة

- أي تعديل بيظهر على الموقع **فوراً** (الصفحة بتقرأ من قاعدة البيانات في كل زيارة).
- **رفع الصور**: في أي حقل صورة تقدر ترفع صورة من جهازك — بتتخزن في **قاعدة
  البيانات** وبتتعرض من `/api/media/…`، فبتفضل موجودة على أي استضافة حتى المجانية.
  (لو عايزها تتخزن على قرص السيرفر حط `MEDIA_STORAGE=disk`).
- **إخفاء بدل الحذف**: أي عنصر مرتبط بحجوزات مش هيتحذف — استخدم زر «إخفاء».
- `npm run seed` بيمسح التعديلات ويرجّع البيانات الافتراضية، فمتشغلوش بعد ما تبدأ
  تعدّل من اللوحة.
- **نسخة GitHub Pages** (الثابتة) مالهاش قاعدة بيانات، فمفيش فيها لوحة تحكم —
  بتتبني بالبيانات الافتراضية الموجودة في `src/data/`.

## البيانات الافتراضية (أول تشغيل بس)

| البيانات | الملف |
| --- | --- |
| الخدمات والعروض والفريق | `src/data/seed-data.ts` |
| الفروع | `src/data/branches.ts` |
| صور المعرض | `src/data/gallery.ts` |
| النصوص وأرقام التواصل | `src/data/settings-schema.ts` |
| الصور | `public/images/` |
| الألوان والهوية | `src/app/globals.css` + `text-[#c9a227]` داخل المكوّنات |

> الملفات دي بتتزرع في قاعدة البيانات مرة واحدة بـ `npm run seed`، وبعد كده
> التعديل الحقيقي بيتم من لوحة التحكم. ونفس البيانات بتشتغل كـ **احتياطي**
> لو قاعدة البيانات مش متاحة، علشان الموقع مايفصلش أبداً.
