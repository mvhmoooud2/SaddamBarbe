# نشر الموقع على Render — رابط دائم شغال 🌍

الطريقة دي بتديك **رابط دائم** فيه الموقع + **لوحة التحكم `/admin`** + قاعدة بيانات
حقيقية، **مجاناً**، في حدود 10 دقايق.

كل حاجة متجهّزة في المستودع (ملف `render.yaml`) — إنت بس بتدوس الأزرار.

---

## قبل ما تبدأ

- حساب على [GitHub](https://github.com) ← موجود ✅
- حساب على [Render](https://render.com) ← اعمله بـ «Sign up with GitHub» (مجاني، من غير كارت)
- **ادمج الشغل في فرع `main`** الأول:
  افتح [الـ Pull Request](https://github.com/mvhmoooud2/SaddamBarber/pulls) من فرع
  `arena/01a0dc01-saddambarber` واعمله Merge.

---

## الخطوات

### 1) اعمل Blueprint
1. ادخل <https://dashboard.render.com/blueprints>
2. اضغط **New Blueprint Instance**
3. اختار مستودع **`mvhmoooud2/SaddamBarber`** (لو مش ظاهر اضغط *Configure account* واسمحله يشوف المستودع)
4. Render هيقرا ملف `render.yaml` ويعرضلك إنه هينشئ:
   - خدمة ويب اسمها **saddam-barber**
   - قاعدة بيانات PostgreSQL اسمها **saddam-barber-db**

### 2) حط كلمة سر لوحة التحكم
هيسألك على متغيّر **`ADMIN_PASSWORD`** → اكتب كلمة سر قوية (دي اللي هتدخل بيها `/admin`
وهتسلّمها للعميل بعدين).

### 3) Apply
اضغط **Apply** واستنى 3–5 دقايق (أول بناء بياخد وقت). Render هيعمل لوحده:
- ينصّب المكتبات
- ينشئ جداول قاعدة البيانات (`npm run db:push`)
- يبني الموقع (`npm run build`)
- يزرع البيانات الافتراضية **مرة واحدة بس** (`npm run db:init`)
- يشغّل الموقع (`npm start`)

### 4) الروابط بتاعتك
هتلاقي الرابط فوق في صفحة الخدمة، بالشكل ده:

```
https://saddam-barber.onrender.com          ← الموقع
https://saddam-barber.onrender.com/admin    ← لوحة التحكم
https://saddam-barber.onrender.com/api/health  ← فحص: لازم يرجّع {"ok":true}
```

## دومين العميل (اختياري لكن مهم للتسليم)

من صفحة الخدمة → **Settings → Custom Domains → Add Custom Domain** →
اكتب دومين العميل (مثلاً `saddambarber.com`) واتبع تعليمات الـ DNS.
شهادة SSL بتتظبط تلقائياً ومجاناً.

## حاجات لازم تعرفها عن الخطة المجانية

| النقطة | التفاصيل |
| --- | --- |
| 😴 السيرفر بينام | بعد 15 دقيقة من غير زوار، وأول زيارة بعدها بتاخد ~50 ثانية عشان يصحى |
| 🗄️ قاعدة البيانات | مجانية لمدة 30 يوم، وبعدها بتتوقف — لازم ترقّي لخطة مدفوعة (~7$/شهر) أو تستخدم [Neon](https://neon.tech) المجانية بدالها |
| 🖼️ الصور المرفوعة | القرص مؤقت → الصور اللي العميل يرفعها من اللوحة ممكن تختفي بعد إعادة نشر |

### الحل النهائي الموصى بيه للعميل
- **الموقع**: خطة Render المدفوعة (7$/شهر) → مفيش نوم + قرص دائم للصور.
- **أو** خلّي الصور تتخزن في قاعدة البيانات نفسها (قوللي أعملها وهي شغل بسيط)،
  وساعتها الخطة المجانية تكفي للتجربة.

## لو حصلت مشكلة

| المشكلة | الحل |
| --- | --- |
| البناء فشل | افتح **Logs** في Render وشوف آخر سطر أحمر |
| `/api/health` بيرجّع `ok:false` | قاعدة البيانات مش متوصلة — اتأكد إن `DATABASE_URL` موجود في Environment |
| الموقع ظاهر بس البيانات افتراضية | معناها الزرع مااشتغلش — شغّل `npm run db:init` من **Shell** بتاع Render |
| نسيت كلمة سر اللوحة | Environment → غيّر `ADMIN_PASSWORD` → **Manual Deploy** |

> ⚠️ **متشغّلش `npm run seed`** على السيرفر بعد ما العميل يبدأ يعدّل — ده بيمسح كل حاجة
> ويرجّع الافتراضي. استخدم `npm run db:init` (آمن، بيزرع لو فاضية بس).
